LPU CSE 326 Syllabus Implementation (Units 1 - 4)

This project strictly implements and demonstrates every key topic prescribed in Lovely Professional University's CSE 326 (Internet Programming) syllabus:

Unit 1

HTML5 Architecture & Semantics

  • Semantic markup: <header>, <nav>, <main>, <section>, <footer>.
  • HTML5 Form controls: text, email, tel, radio, checkbox, select, file upload.
  • Form attributes: required, maxlength, placeholder, novalidate.
Unit 2

CSS3 Layouts, Styling & Animations

  • CSS Grid & Flexbox responsive architecture.
  • CSS3 Variables (:root theme colors & dark mode toggle).
  • Pseudo-classes (:hover, :focus, :checked).
  • @keyframes pulse and scanning animations; media queries for mobile/tablet.
Unit 3

JavaScript Core Fundamentals

  • ES6 syntax: let, const, arrow functions, template literals.
  • Control flow (switch, if/else) for reason-based fee calculation.
  • Arrays, objects, modular methods, event handling with addEventListener.
